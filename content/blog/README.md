# ブログの書き方

記事は、このフォルダに Markdown ファイルを1つ足すだけで公開できます。プログラムは書き換えません。

## 追加手順

1. `_template.md` をコピーする。
2. ファイル名を `2026-10-21-lab-trip.md` のようにする。
   - 半角の英数字とハイフンだけにする。空白は使わない。
   - このファイル名が URL になる。上の例なら `https://shirasunalab.github.io/blog-news/2026-10-21-lab-trip`
   - 同じ日に2本書くときは、ハイフンの後ろを変えてファイル名がかぶらないようにする。
3. 先頭の `---` で囲んだ項目と、その下の本文を書き換える。
4. `main` ブランチに入ると、サイトへ自動で反映される。

GitHub の画面から足す場合は、このフォルダで **Add file** → **Create new file** を選び、`_template.md` の中身を貼り付けてから書き換えてください。

## 先頭に書く項目

| 項目 | 書き方 |
| --- | --- |
| `title` | 記事のタイトル |
| `date` | 画面に出る日付。`2026-10-21` の形 |
| `tags` | タグ。1行に1つ。例はテンプレートの通り |
| `summary` | 一覧カードに出る短い説明 |
| `pinned` | `true` にすると、トップページの新しい3件の候補になる。ふつうは `true` |

`pinned: false` の記事も Blog の一覧には出ます。トップの3件には入りません。

## 本文

`---` の下に、普通の文章で書きます。

- 段落のあいだには、空行を1つ入れる。
- 太字は `**この部分**` のように、アスタリスク2つで囲む。
- 見出し（`#`）や箇条書き、本文中のリンクは、記号ごとそのまま表示される。

## 写真

1. 画像ファイルを `public/images/blog/` に置く。
2. 記事の先頭、`pinned` の次あたりに次を足す。`src` は `/` から始める。

```yaml
images:
  - src: "/images/blog/photo.jpg"
    alt: "写真の説明"
```

写真が2枚以上あるときは、`  - src:` の塊を繰り返します。

## 関連リンク

本文の下に、別枠のリンクとして出ます。

```yaml
links:
  - label: "ノートの記事"
    url: "https://example.com"
```

## お知らせ（News）

研究室のお知らせは `content/news/` に、同じ形式で置きます。Blog 一覧には出ません。News と Blog＆News に出ます。書き方は `content/news/README.md` です。
